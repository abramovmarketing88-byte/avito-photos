# Meaning strategy (хуки и смыслы креативов)

Источник дистиллята: art-director + бан-лист photos.  
Стык с кеглями/плашкой: [overlay-hooks.md](overlay-hooks.md).

## Роли кадров

| Кадр | Задача смысла |
|------|----------------|
| **Cover (hero)** | Search intent + сильнейшая боль или ценность ЦА |
| **Internal (warm-up)** | Конкретная выгода, процесс, снятие возражения, доверие, результат |
| **Final (CTA)** | Прямой призыв + выгода **первого шага** |

База смыслов — анализ объявления (ЦА, боли, желания, возражения), не «красивые общие фразы».

## Формат текста на кадре

Обычно **1 сильный headline + 1 короткий submeaning**. Без длинных списков и простыней.

Паттерны:

```text
[Что делаем]
[Почему это важно покупателю]
```

```text
[Сильная поисковая / сегментная фраза]
[Главная боль, которую снимаем]
```

```text
[Действие / результат]
[Без боли / риска / лишних трат / потери времени]
```

**Не** ставить регалии (стаж, «команда N человек», сертификаты) главным смыслом обложки, если есть боль/выгода. Регалии — поддержка на warm-up, не замена хука.

## Text discipline

- На сгенерированном кадре — **только** согласованный / утверждённый текст смысла (режим E) или auto-hook по правилам ниже (C/D).
- Не добавлять бейджи, цены, контакты, fake UI, чужие цифры, слоганы вне смысла.
- Инфографика без читаемого текста ок (иконки, стрелки, панели); если нужен текст на объекте — только approved / auto-hook слова.

## CTA whitelist

Допустимо:

- «Напишите», «Позвоните», «Напишите в чат»
- С выгодой шага: «Напишите — посчитаем», «Пришлите размеры», «Расчёт сегодня в чат»

Не писать:

- «Напишите в Авито», «Оставьте заявку» (пользователь уже на Авито)
- Внешние мессенджеры / сайты / телефоны на кадре (модерация)

## Бан-лист (совпадает с photos)

На любом кадре запрещено: срочно, акция, скидка, дёшево, ЛУЧШИЕ, №1, 100%, гарантия результата, контакты, QR, сайты.

## Массовый C / D — auto (без approve на строку)

Не truncate Title вслепую. Алгоритм `title_to_hook()`:

1. Выделить **search-anchor** (что ищут в выдаче: «Кухня на заказ», «Бухгалтер для ИП»).
2. Выделить **pain/value** или сегмент («без доплат», «под ключ», «для селлеров») — если есть в Title/Description/USP сета.
3. Headline = 3–6 слов: search ± короткий сегмент; ≤26 символов где возможно.
4. Submeaning (строка 2) = **USP сета / темы** (фиксированный для set-01…set-10 или theme).
5. Строка 3 (hero) = CTA из whitelist.

Пример:

| Title | Hook | USP сета | CTA |
|-------|------|----------|-----|
| Кухня угловая на заказ Москва под ключ | Кухня на заказ | Угловая · под ключ | Напишите — посчитаем |
| Бухгалтер для маркетплейсов отчётность | Бухгалтер для селлеров | Отчёты без штрафов | Напишите в чат |

При создании **новых** 10 сетов или новой theme set — один approve списка смыслов сетов/темы (`SETS-PLAN.md` / `theme-meanings.md`), не на каждый Id.

---

## Режим E — approve цикл

1. Анализ листинга (кратко в ответе).
2. Смыслы на каждый кадр — ждать approve.
3. На генерации использовать **только** approved строки verbatim.
4. После правок пользователя — не возвращать старые формулировки.

Шаблон вывода смыслов:

```text
1. Обложка
[Headline]
[Submeaning]

2. Прогрев
[Headline]
[Submeaning]

…
N. CTA
[Headline]
[Submeaning]
```

## QA смысла

- Хук читается за 1 сек в квадратном превью?
- Есть search-anchor (покупатель узнаёт «это про мой запрос»)?
- Pain/value сильнее регалий?
- Нет бан-листа и контактов?
- CTA из whitelist и про первый шаг?
