# CTR-оверлеи и генерация 4:3 для Авито

Проверенные правила: [rules-audit.md](rules-audit.md).

## Обязательный формат файла

| Параметр | Значение |
|----------|----------|
| Соотношение | **4:3** горизонталь |
| Целевой размер | **1920×1440** |
| Допустимо | **1600×1200** / **1280×960** |
| Формат | **JPG** (осн.), PNG |
| Вес | ≤ **25 МБ**; цель **0.3–2 МБ** |

## Safe-zone 1300×1300 (обязательно)

В выдаче превью часто **1:1** — бока 4:3 обрезаются. Весь продающий текст должен пережить crop.

На кадре **1920×1440** safe-zone:

```
x0 = (1920 - 1300) / 2 = 310
y0 = (1440 - 1300) / 2 = 70
x1 = 310 + 1300 = 1610
y1 = 70 + 1300 = 1370
```

**Весь блок** (плашка + хук + выгода + иконки) рисуется **только** внутри `(310,70)–(1610,1370)`.

Брак:

- тонкая полоска у самого низа кадра, если текст визуально «пропадает» в миниатюре;
- текст у левого/правого края вне 1300;
- хук не читается с телефона.

Проверка: обрезать центр **1:1** (или центр 1300×1300) — хук и выгода видны целиком и крупно.

## Площадь оверлея: 10–25%

Площадь = `ширина_плашки × высота_плашки / (1920×1440)`.

| Композиция | Доля оверлея | Когда |
|------------|--------------|--------|
| Много «воздуха» снизу / чистый пол | **18–25%** | можно крупный блок |
| Товар плотно внизу кадра | **10–15%** | не закрывать фасады |
| Типичная мебель в интерьере | **15–20%** | дефолт пайплайна |

Раньше в скилле стояло «≤10%» из осторожной трактовки блога Авито — для **этого** CTR-пайплайна пользователь зафиксировал **10–25%** и читаемость с телефона как приоритет. Не ужимать текст ниже 10% «на всякий случай».

Не превышать **25%** и не превращать кадр в баннер (простыня, прайс, 6 строк).

## Обложка — формула

| Доля | Что |
|------|-----|
| 60–80% | товар в интерьере |
| **10–25%** | плашка + короткий хук (+ выгода) **внутри 1300×1300** |
| 0% | прайс, визитка, телефон, коллаж |

Ощущение: товарное фото с читаемым УТП, не слайд маркетплейса на полкадра.

## Текст

| Слой | Лимит | Кегль @1920 | Пример |
|------|-------|-------------|--------|
| Хук | 3–6 слов | **72–110 px** | «ТВ-зона на заказ» |
| Выгода | 3–6 слов | **44–64 px** | «Под ваш интерьер» |

Контраст: светлый текст на тёмной плашке (или наоборот). Тень/обводка для мобилки.

### Бан-лист

Контакты, QR, сайты, мессенджеры; стоки; чужие лого; рамки; watermark-сетка;  
«срочно», «акция», «скидка», «дёшево», «ЛУЧШИЕ», «№1», «100%», «Гарантия результата»;  
перечёркнутая цена; UI Авито.

Логотип свой: не обязателен; если есть — угол safe-zone, ≤8%.

## Геометрия плашки (рекомендуемый дефолт @1920×1440)

Для доли ~**18%**:

- Ширина плашки ≈ **1200–1300** (центрировать в safe-zone)
- Высота плашки ≈ **300–360** px → площадь ≈ 16–21%
- Позиция: нижняя треть **safe-zone** (нижний край плашки ≤ y=1370, не ниже)
- Padding текста внутри плашки ≥ 24–36 px

Пример якоря:

```
panel_w, panel_h = 1280, 340
panel_x = (1920 - panel_w) // 2          # ≈ 320 ≥ 310
panel_y = 1370 - panel_h - 20            # внутри safe-zone
```

## Свет / цвет / фон

Дневной мягкий свет; натуральные цвета; без кислоты/HDR.  
Интерьер чистый; товар 60–80%.

## Галерея (до 10)

1 обложка+УТП → ракурсы → детали → масштаб → опц. длинный УТП в хвосте.

## Уникальность

Разные lead и вариации хуков между объявлениями.
