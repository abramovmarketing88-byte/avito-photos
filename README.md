# Avito Photos

Cursor Agent Skill: фото и `ImageUrls` для автозагрузки Авито через Яндекс.Диск + CTR-оверлеи + премиум арт-дирекшн.

Стартовая точка: [`SKILL.md`](SKILL.md)

**Режимы:** A (только URL) · B (генерация/оверлей) · C (сеты 10×4 + heroes) · D (storyline услуги) · **E** (арт-дирекшн: смыслы → 3 обложки → карусель → handoff в ImageUrls).

Работает вместе с [`avito-factory`](https://github.com/abramovmarketing88-byte/avito-factory) (тексты/Excel) и [`avito-api`](https://github.com/abramovmarketing88-byte/avito-api-skill) (выгрузка/загрузка).

См. полный список скиллов Авито: [avito-factory/README.md](https://github.com/abramovmarketing88-byte/avito-factory#скиллы-авито-в-экосистеме).
